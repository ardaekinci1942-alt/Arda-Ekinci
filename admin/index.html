Yönetim Paneli

Fotoğraf yüklemek ve siteni düzenlemek için GitHub anahtarınla giriş yap.

Anahtarı nasıl alırım?
  1. github.com/settings/personal-access-tokens/new adresini aç.
  2. İsim: ardaekinci-admin, süre: istediğin kadar (ör. 1 yıl).
  3. Repository access → Only select repositories → Arda-Ekinci.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Generate token'a bas, çıkan kodu buraya yapıştır.

Bu anahtar yalnızca senin repona erişir. Kimseyle paylaşma.
