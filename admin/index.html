Anı eklemek ve siteni düzenlemek için GitHub anahtarınla giriş yap.

Anahtarı nasıl alırım?
  1. github.com/settings/personal-access-tokens/new sayfasını aç.
  2. İsim ver (ör. site-admin), süre seç.
  3. Repository access → Only select repositories → Arda-Ekinci.
  4. Permissions → Contents → Read and write.
  5. Generate token'a bas, çıkan kodu kopyala ve buraya yapıştır.

Bu kod sitenin anahtarıdır, kimseyle paylaşma.
